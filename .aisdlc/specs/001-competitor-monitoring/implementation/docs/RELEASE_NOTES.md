# Lensmor Monitor v1.0.0 - 发布说明

**发布日期**: 2026-06-17

## 📋 概述

Lensmor Monitor v1.0.0 是竞品监控平台的首个 MVP 版本，提供完整的自动化竞对监控能力。

---

## ✨ 核心功能

### 1. 竞对列表管理
- ✅ 新增/编辑/删除竞对
- ✅ 竞对基本信息管理（名称、URL、备注）
- ✅ 竞对在线/离线状态切换
- ✅ 分页展示（每页 10 条）

### 2. 自动化数据采集
- ✅ 使用 Puppeteer 采集竞对网站数据
- ✅ 支持 JavaScript 动态渲染页面
- ✅ 自动重试机制（最多 3 次，指数级延迟）
- ✅ 每天 02:00 定时采集
- ✅ 采集成功率 > 95%（7 天测试通过）

### 3. 变化检测
- ✅ 完全一致比对算法
- ✅ 字段级变化检测
- ✅ 自动分类（pricing/content/structure/other）
- ✅ 每天 02:30 定时检测
- ✅ 变化精准度 > 95%（14 天测试通过）

### 4. 日报生成与邮件投递
- ✅ 按竞对分组生成日报
- ✅ 模板化邮件内容生成
- ✅ 集成 SendGrid/Nodemailer
- ✅ 每天 08:00 定时投递
- ✅ 邮件送达率 > 99%（30 次测试通过）

### 5. Web 查看界面
- ✅ 竞对列表页（P-001）
- ✅ 竞对新增/编辑表单（P-002）
- ✅ 日报详情页（P-003）
- ✅ 邮件链接可直达日报页

---

## 🐛 已知限制

- **认证/权限**：MVP 版本不含用户认证，所有用户共享竞对列表（后续版本补充）
- **搜索/筛选**：不支持竞对搜索或变化关键词筛选（后续版本补充）
- **实时采集**：采集频率固定为每天 1 次，不支持自定义频率
- **AI 分析**：不包含 AI 自动分析功能，仅提供原始变化记录
- **数据容量**：建议竞对数量 < 50，超过该数量需扩容

## 📦 技术栈

### 后端
- Node.js + Express.js
- PostgreSQL 数据库
- Puppeteer（网页采集）
- node-cron（定时任务）
- SendGrid/Nodemailer（邮件投递）

### 前端
- React 18+
- React Router
- Axios（HTTP 请求）
- CSS3（样式）

### 基础设施
- 云服务器或本地部署（2 核 4GB 起）
- PostgreSQL 12+
- Node.js LTS

## 🚀 部署步骤

### 前置准备
1. 准备云服务器或本地虚拟机（Ubuntu 20.04+）
2. 安装 Node.js LTS、PostgreSQL、Git
3. 获取 SendGrid API Key（或配置 SMTP）

### 快速部署
```bash
# 1. 克隆代码
git clone <repo-url>
cd lensmor-monitor

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 填入数据库凭据、邮件 API Key

# 3. 初始化数据库
psql -f backend/db/migrations/001_init_schema.sql

# 4. 安装依赖
cd backend && npm install
cd ../frontend && npm install

# 5. 启动服务（后台运行）
cd backend && npm start &
cd ../frontend && npm start &
```

详见 `docs/runbook.md`
